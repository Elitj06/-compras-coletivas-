# Critérios de aceitação

- [ ] Após redefinir o PIN, só existe o modal de login; nenhum modal de recuperação permanece no DOM.
- [ ] O login imediato com o novo PIN fecha todos os modais e estabelece a sessão normalmente.
- [ ] O botão **Voltar** da recuperação retorna ao login sem deixar modal residual.
- [ ] A recuperação não autentica automaticamente e continua revogando as sessões existentes.
- [ ] Testes, sintaxe, build, deploy e smoke de produção aprovados.
