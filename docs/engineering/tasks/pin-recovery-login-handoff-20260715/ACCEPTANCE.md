# Critérios de aceitação

- [x] Após redefinir o PIN, só existe o modal de login; nenhum modal de recuperação permanece no DOM.
- [x] O login é apresentado imediatamente para que o comprador entre com o novo PIN, sem modal residual.
- [x] O botão **Voltar** da recuperação retorna ao login sem deixar modal residual.
- [x] A recuperação não autentica automaticamente e continua revogando as sessões existentes.
- [x] Testes, sintaxe, build, deploy e smoke de produção aprovados.
